# Page Layout Designer

Lay a page out by numbers instead of dragging by eye.

The page is cut into rows, top to bottom. Any box can be cut again, side by side or top to
bottom, as often as needed. Each size is set in dots, shares the room left over, or fits what
is inside; each gap is the usual one, a number of its own, or spread evenly. Everything is
worked out from the numbers, so it lines up by itself.

Open it: https://karimcjaafar.github.io/page-layout-designer/

"Copy the plan" gives the layout in plain words, every box's position, and the exact plan.
